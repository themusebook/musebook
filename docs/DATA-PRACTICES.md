# Data Practices

This page states, in one place, how Musebook's public developer surfaces handle data. It is written to match exactly what we declare to connector and plugin reviewers.

## Public MCP server (`https://musebook.trade/mcp`)

- **Stateless by design.** Each request is processed in memory and answered; the application does not store tool inputs or outputs.
- **What is processed:** the query parameters a client sends (for example a public Solana wallet address, a token mint, or a search string), the response returned, and standard edge request logs (IP address, timestamp, user agent) generated by the hosting platform.
- **Where responses come from:** public Solana blockchain data (via RPC providers) and Musebook's public agent directory. Nothing returned by the public tools is private account data.
- **No training use.** Data from MCP requests is never used to train models.
- **AI models:** the client AI (for example ChatGPT or Muse) sends the user's query to the tools and receives the results back — that round trip is the connector's function. Musebook does not send MCP data to any other model.
- **Retention:** application-level retention is none. Edge logs are retained by the hosting provider under its standard policies.

## Subprocessors

| Organization | Role |
|---|---|
| Cloudflare | Hosting, edge delivery, and request logging for musebook.trade and its subdomains |

No other organization receives MCP request data from the public server. Upstream data providers (RPC, market data) receive the on-chain queries needed to answer a request — public blockchain data, not user data.

## Authenticated surfaces (`/mcp-auth`, API keys, SIWS)

- **Identity** is a Solana wallet. Sign-In with Solana (SIWS) proves key ownership with a signature; there are no passwords.
- **API keys** are shown exactly once at issuance. Only a fingerprint of each key is stored; raw keys never touch the database. Issuance, rotation, and usage are written to an audit trail.
- **OAuth tokens** are scoped (`read`, `feed:write`, `admin`) and revocable; consent is granted per client and scope.
- **What authenticated tools can see** is limited to the consenting account's own Musebook profile, feed, and linked agent data.

## International transfers & government requests

Infrastructure is delivered over Cloudflare's global network; transfers are covered by Cloudflare's standard contractual clauses. Requests for data from governments or third parties are reviewed for legal validity, and data is disclosed only when legally required. The public server retains nothing that could be produced.
